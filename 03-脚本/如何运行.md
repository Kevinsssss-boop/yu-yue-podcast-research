# 脚本 · 如何运行（零基础版）

> 这一页教你怎么把脚本跑起来。
> 你不需要懂编程，照着做就行。**每一步都能复制粘贴。**

**目前有两个脚本，按编号顺序跑：**

| 脚本 | 干什么 | 什么时候跑 |
|------|--------|-----------|
| `01-采集粤语播客.py` | 采集节目 + 单集 | 需要补采新节目时 |
| `02-生成打标工作台.py` | 生成语言打标表给你填 | 采完数据后（现在这一步） |

---

## 〇、先搞清楚三个东西

| 名词 | 是什么 | 打个比方 |
|------|--------|---------|
| **脚本**（.py 文件） | 一段"写好的指令"，纯文本，能用记事本打开 | 一份**菜谱** |
| **终端 / 命令行** | 一个黑框框，你在里面**输入命令**、按回车执行 | 你跟电脑**说话的地方** |
| **运行脚本** | 让电脑照着这份"菜谱"干活 | 喊一声"**开做**" |

**你日常只需要做两件事**：① 用 VS Code 打开脚本看/改；② 在终端里敲一句命令让它跑。

---

## 一、运行它（推荐方式：在 VS Code 里）

**第 1 步 · 找到脚本**

VS Code 左边是文件树。依次展开：

```
yu-yue-podcast-research  →  03-脚本  →  01-采集粤语播客.py
```

**第 2 步 · 在脚本所在的文件夹打开终端**

**右键点这个 `.py` 文件** → 菜单里选「**在集成终端中打开**」（英文版叫 *Open in Integrated Terminal*）。

> 这一步会自动帮你"切换到脚本所在目录"，省得你手动敲路径。
> 如果找不到这个菜单项，就用下面的「备选方式」。

**第 3 步 · 敲命令、回车**

终端窗口出现后，里面**已经在一个文件夹里**了。直接把这行粘进去，按回车：

```
python "01-采集粤语播客.py"
```

（粘贴：`Ctrl + V`；如果没反应，右键 → 粘贴）

**第 4 步 · 看它跑**

你会看到一堆滚动的字，类似：

```
第 0 步：检查已有数据
  发现已经采过 435 个节目
  → 这些会【自动跳过】，不重复采
  → 新采到的会【追加】到文件末尾，老数据一个字节都不动

第 1 步：收集候选节目
  「粤语」× cn → 返回 80 个，其中新的 0 个
  ...

  人工种子清单（共 15 个）：
    + 见面倾啦
    + 生而為人邊有咁簡單
    ...

  >>> 本次需要新采：15 个节目
      （已采过 435 个，自动跳过）

第 2 步：下载并解析每个节目的 RSS
  [1/15] 见面倾啦
          → 解析出 44 集
  ...

第 3 步：保存结果（追加到已有文件末尾）
  [OK] 新增节目：15 行  →  内容侧_节目表.csv
  [OK] 新增单集：1234 行  →  内容侧_单集表.csv
  [OK] 失败清单：0 个节目  →  采集失败清单.csv

  现在节目表共 450 个节目。
```

**看到最后的 `现在节目表共 XXX 个节目` 就是成功了。**

## 四、增量采集：这个脚本**可以反复跑**

**核心规则一句话：已有的自动跳过，只采没有的，新数据追加到文件末尾。**

所以你不需要"先测试再全跑"两次——直接跑就行。而且：

| 你做了什么 | 下次跑会怎样 |
|-----------|------------|
| 什么都不改，再跑一次 | 提示"没有新节目要采"，几秒结束 |
| 加了新的关键词 | 只采新关键词捞到的新节目 |
| 在 `SEED_FEEDS` 里加了人工种子 | 只采那个新加的节目 |
| 把某个 feed 从 `SEED_FEEDS` 删了 | **不会删除已采的数据**（给表是追加的） |

> ⚠️ **唯一要注意的**：跑的时候**别关代理**（Clash 要开着），
> 否则海外那几个源连不上，会进失败清单。

**要把结果整个清掉重来**：删掉 `01-原始数据/` 里**全部** csv，再跑一次。
（只删单集表不删节目表的话，脚本会以为"已采过"而跳过，数据就回不来了。）

## 五、常见问题

| 现象 | 原因 / 怎么办 |
|------|--------------|
| `python : 无法将"python"项识别为...` | 电脑没装 Python，或没加到 PATH。截图发我 |
| `No module named 'requests'` | 缺一个库。终端里跑 `pip install requests` 再试 |
| 终端里中文变成乱码方块 | 显示问题，**不影响结果**——CSV 打开是正常的 |
| 跑一半卡住不动 | 可能在下载一个大 RSS，等一两分钟。真卡死就 `Ctrl + C` 停掉 |
| `× 连不上，已跳过` | **正常**——有的播客服务器连不上（域名被墙/停运）。会记进失败清单，**不影响其他节目** |
| `⚠️ 这个 feed 一集都没有！` | 这个 RSS 地址本身有问题（常见于电台的"空壳 feed"）。会记进失败清单 |
| 提示 `没有新节目要采` | 说明数据是最新的，不是出错 |
| `✗ 下面这些文件正被别的程序占用，写不进去` | **Excel / WPS 正开着那几个 CSV**。关掉那些窗口再跑 |
| `PermissionError: [Errno 13] Permission denied` | 同上——文件被占用。**在 Excel 里关掉那个表格的窗口**（不用退出 Excel），再跑 |
| 想把结果清掉重来 | 删掉 `01-原始数据/` 里**全部** csv，再跑一次 |

**任何报错，把终端里的红字复制发给我**，我来看。

## 六、脚本做了什么（一句话版）

```
关键词搜索 + 人工种子
      ↓ 合并去重、跳过已采过的
逐个下载 RSS
      ↓ 拆开
节目表（1 行 = 1 节目） + 单集表（1 行 = 1 集）
      ↓ 追加
写进 CSV（老数据不动）
```

代码里每一段都有中文注释，你打开 `01-采集粤语播客.py` 就能看懂每一行在干嘛。

## 七、脚本里两个可以改的地方

**① `KEYWORDS`（脚本第 31 行）—— 关键词搜索清单**

**② `SEED_FEEDS`（脚本第 51 行）—— 人工种子清单**

```python
SEED_FEEDS = [
    ('见面倾啦', 'https://feed.xyzfm.space/8xrynrfhcvuy'),
    ...
]
```

**为什么需要它**：苹果搜索只能按关键词匹配元数据。有些粤语播客的元数据里
**根本不含"粤语/廣東話"**（比如「见面倾啦」只写了"栋笃笑"），
关键词怎么调都搜不到，只能人工把 RSS 地址填进来。

**你要加新节目时**：找到它的 RSS 地址，按 `('节目名', 'RSS地址'),` 的格式加一行，
保存，再跑一次脚本就行。

### 你要填什么

打开后，**只看最后两列**（★ 开头的是给你填的）：

| 列 | 填什么 |
|----|--------|
| **★你的语言判定** | `粤语` / `非粤语` / `不确定` |
| **★你的备注** | 可选，写理由 |

**按 `优先级` 从上往下过**：

| 优先级 | 数量 | 你要做什么 |
|--------|:---:|-----------|
| **①逐个看** | 56 | ⬅ **只有这些必须你逐个判断** |
| ②反向标志 | 17 | 扫一眼，基本都是非粤语，确认即可 |
| ③坏数据 | 3 | 0 集，直接填「非粤语」 |
| ④单集救回 | 5 | 单集标题证明是粤语，确认即可 |
| ⑤抽查 | 369 | 抽 20 个看看就行，不用全填 |

> 💡 表格里有两列帮你判断：
> - **`判定依据`** —— 机器凭什么这么判（如 `A类「粤语」@简介`、`无标志`）
> - **`单集标题样例 ×3`** —— **机器看没用，但你看有用**（看到「创世记 第一章」还是「咁样嘅人生」你一眼能判）
>
> ⚠️ **`内容形态` 这列是我自动填的，有时会不准**（比如「【广播剧】专辑」被标成"音乐"）。
>    看到明显不对的，在备注里写一下就行，我来改。
