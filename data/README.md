# 数据说明

本目录只放**汇总级**数据，原始单集表（70 MB / 46 MB）因体积与内容版权未纳入仓库。

## 文件清单

| 文件 | 行数 | 说明 |
|------|-----:|------|
| `节目表_粤语.csv` | 374 | 节目层元数据：名称、平台、主播、简介、形态、集数 |
| `内容形态_定稿.csv` | 57 | 喜马拉雅 57 档节目的形式标签（人工核对） |
| `内容主题_定稿.csv` | 57 | 喜马拉雅 57 档节目的主题标签（人工标注） |
| `主题_全量.csv` | 374 | 全部节目的主题标签，含「来源」和「命中」两列可追溯 |
| `喜马拉雅节目汇总_A+B.csv` | 57 | 播放量汇总，含全量与近 12 个月两套口径 |

## 原始数据怎么重建

原始单集表可通过脚本重新生成：

```bash
python scripts/01-采集粤语播客.py   # 约 40 分钟，产出 01-原始数据/
python scripts/03-清洗数据.py       # 产出 02-清洗后数据/
```

需求侧（喜马拉雅播放量）需通过浏览器自动化采集，
清洗脚本为 `scripts/05-清洗喜马拉雅播放量.py`。

## 数据来源

- 节目与单集元数据：苹果播客目录（iTunes Search API）→ 各节目公开 RSS
- 播放量：喜马拉雅专辑页公开列表

所有数据仅用于学术研究用途。原始单集标题与简介的著作权归各节目创作者所有。
